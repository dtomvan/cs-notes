# Week 1

## Lecture 1 -- A short history of Computing Science

Date: Tue 1 Sep 2026 (2026-09-01)

### Computing technology (CT)

- 35 000 BC: Tally sticks
- 2500 BC: abacus
- 100 BC: Antikythera (GRC)
- 17th century: improved abacus, slide rule
- 19th century: cathode ray tube (display), electromechanical tabulating machine using relays etc.
- 1900-1939: vacuum tubes as transistors, flip-flop circuits
- 1940-1949: first programmable computer, actual transistors and magnetic mem
- 1950-1959: integrated circuits
- 1960-1969: first neural network, robot, mouse, VR-helmet, calculator, arpanet
- 1970-1979: floppy, microprocessor, PC, email, glass fiber
- 1980-1989: IBM PC, CD, supercomputer
- 1990-1999: optical processor, DNA comp, laptop, PDA

### Computing science (CS)

- Clay tablets with cuneiform -> accounting :rofl:
- 3500 BC: symbolic notation
- 300 BC: binary notation
- 17th century: binary computing rediscovered
- 19th century: Boole figured out booleans (haha), Babbage, Ada
- 20th century: Turing
- ~WWII: programmable computer, hypertext
- 1950s: Fortran, Lisp, Cobol, subroutines, compiler, concept of AI
- 1960s: Algol, Basic, Pascal, Pong, CGI, software engineering as we know it today
- 1970s: Smalltalk, C, Prolog, Ada, Telnet, FTP, spreadsheets, complexity, NP-completeness etc.
- 1980s: C++, TCP/IP, MIDI, Postscript, DOS, Windows, chat, www, hacking
- 1990s: Java, browsers, search engines, quantum computing
